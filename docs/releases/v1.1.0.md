## What's Changed

- Notifications now use the DailyWingetNotify app icon as the large message icon when Windows supports custom tray balloon icons.
- `winget` is started with English locale via `--locale en-US` so update parsing can rely on English output.
- Release automation now enforces SemVer tags and release notes.
