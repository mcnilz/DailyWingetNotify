## What's Changed

- Release builds now embed the SemVer release tag in the executable metadata.
- The About dialog now displays the embedded release version, for example `DailyWingetNotify v1.1.1`.
- The release workflow now passes tag-derived version metadata to `dotnet publish` and checks out the requested tag for manual release runs.

**Full Changelog**: https://github.com/mcnilz/DailyWingetNotify/compare/v1.1.0...v1.1.1
